## 跨池对照

面板只读对照三个池：当前 `SPY/PAIR 1%`、候选 `PAIR/USDG 1%` 和候选
`PAIR/USDG 3%`。候选池使用当前市场流动性，把我们的现有美元本金与四个美元价格区间
静态映射过去，再按历史 Swap 估算可捕获费用；这不是历史实盘仓位，也不是交易模拟。

决策门要求 6 小时和 24 小时窗口都完整、候选池在两个窗口都领先当前池至少 30%，且
20% 试仓的模型迁移成本可在 8 小时内回收。迁移成本读取当前 gas price 与 ETH/USDG
只读报价，但仍不是待签名交易的 preflight。首次上线核验时 6 小时窗口完整，24 小时
窗口尚未覆盖完整锚点，因此信号为 `BUILDING_EVIDENCE`，不会触发调仓。

RPC 端点不出现在网页、API 响应或项目日志中。服务不加载任何钱包或私钥。

## 运维边界

新建、迁移或永久退出任一 LP 后，必须先在项目根目录运行 `npm run portfolio:build`，确认
钱包链上 NFT 集合与本地账本无差异，再重新发布生成的生命周期 manifest。普通价格、
手续费、钱包余额、成交量和已知 NFT 的区间内外状态不需要手工操作，会自动更新。
